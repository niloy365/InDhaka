# 🚌 inDhaka

> A smart public transportation route finder for Dhaka, Bangladesh.

**inDhaka** helps users find public transportation options between two locations in Dhaka, including **Bus, Leguna, and Metro Rail**.

The project is being rebuilt with a Python backend and a modern web deployment setup using **Vercel** and **Neon PostgreSQL**.

---

## 🚀 Project Overview

Finding the right public transportation route in Dhaka can be difficult because information about buses, legunas, metro stations, fares, and routes is scattered across different sources.

inDhaka aims to provide a single platform where users can:

- 📍 Select a **From** location
- 📍 Select a **To** location
- 🚌 Find matching buses
- 🚐 Find matching legunas
- 🚇 Find Metro Rail routes
- 💰 View transportation fares
- 🗺️ View routes on a map
- 🖼️ See transportation images
- 🔎 Search transportation options
- 🤖 Eventually use an **AI assistant** to help users plan their journey
